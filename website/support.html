You can drag tabs to reorder them or use the Window menu. Reopen Closed Tab keeps up to 20 recently closed tabs. Clear that list with File → Clear Recently Closed Tabs.

Saving and closing are separate

Save and Save As write to the file you choose. NoteHush also keeps private recovery copies of your drafts and edits. Quitting or closing the red window control exits without an unsaved-file confirmation; reopening restores your workspace, including unsaved text.

Undo history belongs to each open tab during the current session. Closing a tab or restarting the app ends that undo history; restored text and your place in it are kept separately.

A recovery warning appeared

Use the warning’s Export… action to preserve the available drafts or original recovery data in a location you choose. Retry asks NoteHush to try recovery again. Keep exported recovery files private: they can contain your text and file references.

Private recovery is not a substitute for backups. A disk failure, power loss or forced termination can interrupt the latest write. Keep important work in explicitly saved files and your own backup system.

A file moved or changed

If a file is no longer accessible, keep your recovered draft and use the relink or Save As options. If another app changed the file, NoteHush asks how to resolve that change during an explicit save. Your private draft does not silently replace the external file.

Supported text files

NoteHush opens UTF-8, UTF-8 with a byte-order mark, and UTF-16 with a byte-order mark. It preserves supported source encoding and line endings. Invalid or unsupported bytes are rejected so the original file stays intact.

Files larger than 100 MiB cannot be opened. NoteHush does not display PDF, Word, rich-text or spreadsheet documents, and it does not provide cloud sync.
