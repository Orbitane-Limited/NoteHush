## Findings resolved

- Foundation string decoding can consume a literal leading U+FEFF after the encoding BOM is already removed. Swift decoding with exact code-unit/byte validation preserves it and rejects repaired malformed input.
- `NSFileCoordinator` can block before its accessor on a FIFO. Descriptor type/size checks now run before coordination and again for the actual read, with nonblocking, no-follow descriptor flags.
- Panel automation must use actual accessibility identifiers, scope buttons to sheets to exclude Touch Bar controls, and target `saveAsNameTextField` rather than the separate visible label. Temporary UI diagnostics are removed from the committed tests.
- This Mac has an enabled system screen-capture binding for Command-Shift-S (symbolic hotkey 184). Sending it started `screencapture` and blocked subsequent event synthesis. Save As tests invoke the native menu; the system preference is unchanged. Physical shortcut delivery needs a host without that global override. The app retains the standard Command-Shift-S menu binding.
- Native file panels prevent termination before consulting the app delegate by default. Open/Save panels now set `preventsApplicationTerminationWhenModal = false`; shutdown uses the panel's cancellation action to resume Save As before draining recovery. A dedicated quit/relaunch UI regression verifies this path.

## Review and limits

Self-review covers immutable save snapshots, unchanged dirty state after failure, exact-byte undo comparisons, balanced security scopes, duplicate destinations, cancellation, quit ordering and read-only recovery protection. No independent reviewer approval is claimed.

Persistent bookmarks, relink and inspect/reload/explicit-overwrite choices remain issue #7. A recovered path is metadata, not sandbox authority; Save currently asks for a native destination after relaunch. Changed/deleted originals are refused, with Save As available. OS coordination waits are not instantly cancellable; late results cannot install a cancelled tab.

Files above 100 MiB are refused; above 20 MiB show a notice. Performance, large-workspace memory/recovery-envelope limits, minimum-macOS and Intel runtime evidence remain M5. Local UI signing is ad hoc with sandbox verified; production signing, hardened runtime, external-volume testing, TestFlight and App Review remain M6 gates. No release is published.

The privacy manifest declares file metadata reason `3B52.1` for user-granted files, checked against [Apple's required-reason API categories](https://developer.apple.com/documentation/bundleresources/app-privacy-configuration/nsprivacyaccessedapitypes/nsprivacyaccessedapitype). No collection or tracking is added.
